# 📝 Python Quiz Game

## 📌 About the Project
Python Quiz Game is an interactive quiz application
that presents multiple-choice questions to the user.

The user selects an answer, and the program checks
whether the answer is correct.

## ✨ Features
- Multiple-choice questions
- Question and option display
- Answer validation
- Interactive quiz gameplay
- Educational question format

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

   python quiz_game.py
